# AZCine 设计规范

> 更新：2026-10-04。只记当前有效视觉与交互，不放测试流水账。整体方向冻结：亮暗同布局、首页B、公司卡片→自由文档、正常通用聊天；只按阶段补必要状态。

## 1. 体系与共用规则

以 product_6.0 出厂 tokens/base/所需零件为底，项目现有 `design/tokens.css`、生产 `app/src/styles/` 为落地。新状态先沿用体系，不擅自重选方向；新增方向确需用户选择时按原设计阶段执行。项目标签组件是已明确的例外：直接开发，不另做方向确认。

### 颜色

主题显式 `data-theme`；未手动选择跟随系统，手动选择本机保存。基础体系仍以灰阶面与唯一强调色为主，弹层可用出厂阴影。项目已确认的局部例外：入口卡片底部可用强调浅色淡渐变，list/清单用细分隔与轮廓区分操作区域，阶段标签用不同色相的底色小圆角；不把这些例外扩成全站新配色或重选方向。

### 排印、尺寸与动效

- 系统无衬线，Windows中文Microsoft YaHei；编号/数字用Consolas或现有mono，无网络字体。
- 页标题20/28/600；区/条目标题16/24/600；正文控件14/22/400；次级13/20；元信息12/18。标题可换行、URL可断行，不缩字号塞内容。
- 特定语义：feature数字32/40 mono；公司可编辑名称24/32、文档段落16/28；新闻正文17/30、文章标题28/38，不把所有页面放大。
- 间距4/8/12/16/24/32/48/64；圆角岛18、面板14、控件10、小件6。共用变量优先，不一处一个数。
- 通用按钮高≥40，主按钮44；通用复选框视觉18、命中区40。项目清单已确认的紧凑局部控件按第3节尺寸，保留实体焦点与可访问名。140ms只用于悬停/选中/展开；减少动态偏好关闭，不自动闪烁/循环。

## 2. 壳、导航与首页B

- 顶部40留桌面标题与系统按钮；外距16，导航176、主面间隔16，普通主内容内距32。今天与项目采用容器内距24，不把内容压成居中窄栏；项目入口、详情均从主容器左侧对齐。真实系统按钮/拖动由桌面负责，HTML不冒充可用系统壳。
- 基准1440×900、常用1280×800、最小1024×768。≤1100导航80、普通内容内距24、今天内距16，项目仍用24；先收辅助区再收留白，不裁按钮或硬缩字。
- 主导航今天/项目/资讯/模型榜/灵感/Agent/后台任务是正常页面，设置在底部；Agent入口前留24分组。当前页 `aria-current`，主题/筛选 `aria-pressed`。
- 共用外壳占窗口可用高度：顶部、左侧导航、模块标题固定，主容器顶底和圆角边界始终在窗口内；正文只在右侧模块内容区内部滚动，不带动整个页面和左侧导航。内容多时左导航可在自身区域滚动，不能与正文联动。页标题/右侧动作共中心线、区标题同基线。此规则供所有现有及后续模块复用。
- 完整AZCine字标用 `assets/brand/logo-lockup.png`，保完整形状，不再拼“AZ方块+文字”；亮色黑字、暗色同形浅字，窄导航等比缩小不裁字。
- **首页只用B·工作双栏**：待核对整行在上，待办/最近交付等宽双栏，资讯整行在下。卡片内距24、间距16；对象直接进入正常详情。未接入模块明确说明，不用演示数据/虚构计数冒充正式内容。
- 待办标题必填，可选完整日期和公司项目；新增区用短标题输入＋日期/项目辅助行，筛选/列表是主内容，不铺长标签表单占满首屏。保存失败保草稿，完成可单次撤销/恢复，来源可回查。首页交付由指定list派生。
- 项目和待办共用日期输入＋日历图标；浮动月历含明确年月、上/下月、周一至周日与日期网格、今天/清空，可键入完整YYYY-MM-DD。选择/取消不猜年份；方向键日/周、PageUp/Down月份、Home/End周边、Enter选择、Escape返回触发按钮、Tab可离开。弹层在top-layer，不挤行或被横滚裁切，沿用灰面/唯一强调色。
- 今天就地显示固定高度操作状态与撤销区；异步操作中保持按钮/输入/列表位置和样式，局部等待状态与aria-disabled保护防连点，不整组褪色，不替换已有列表为加载段落。读取失败保旧数据并明确提示，未接入信息仍不造假。

## 3. 公司项目：入口与文档

### 卡片入口

- 项目入口使用主容器全宽，公司/个人两个section；工具栏、区标题、卡片网格与个人待定块统一左对齐，不保留最大1120居中窄栏。
- 公司入口用小尺寸双层卡片：网格最小列宽248、卡片最大320、间距16，随容器宽度自动增加/减少列数；不固定两列或随项目数少拉成大卡。身份区130高/内距16，底部交付区90高，所有状态的色块分界线对齐。
- 顶行文件夹图标＋公司项目/内容块数，标题最多两行、简介一行省略；底部统一为交付状态/完整日期或日期待补或暂无安排/数量与待补信息，右侧小圆角箭头入口。名称、内容标题和交付摘要由正式文档派生，不编数据或重复录入；长文本不撑乱卡片高度。
- 搜索和“新建公司项目”有正常页落点（`projects-new`），不弹窗代替；个人模块仅待定块，不加创建/内部假功能。
- 不恢复旧四页签、旧镜头详情表、部门/团队/本轮修改演示块或素材索引器。

### 文档与交付摘要

- 详情使用主容器全宽，顶部固定返回/面包屑、短保存状态、可改名称、清单展开/收起、保存与添加内容；标题无框，不用长技术说明占首屏，不再设独立阶段标签页头动作或大管理面板。保留正常新建/搜索/返回路径。
- 下方左右布局：左侧项目清单宽240～280（按容器约20%分配）、右侧文档使用其余宽度、间距24；各自内部滚动，项目操作区不跟随正文滚走。收起清单后正文占满；≤1100默认收起，可在项目容器内展开280以内的左侧面板，不硬挤表格。
- 添加内容用按钮旁紧凑菜单，文字/表格list/项目清单各有同体系线性图标、名称和一句说明；不插入大面板推下摘要。上方与文末共用同一菜单，新增项目清单出现在左栏并定位，不追加到正文底部；新表仍默认不汇总。菜单方向键/Home/End、Enter/Space、Escape/外点均可用，取消不改数据。
- 摘要灰面内距24：左侧反色最近交付卡240宽，1280时208；与右侧日期/阶段分组间距32/24。≤1100改上方横卡、下方分组。两列顶对齐，不让左卡被右侧长内容拉伸。
- 最近日期卡用年份12、月日32的feature排印；机器日期和输入始终完整 `YYYY-MM-DD`，跨年不丢年份。其他日期分组保完整日期语义。
- 默认展示前三个日期组，每组默认20条，能展开全部；按日期和稳定阶段ID归组、镜头链接回原行。缺日期/字段单列待补，已交完排除待交，恢复重入；不能猜项目总截止日。
- 右侧正文只排文字和list，可添加/排序/删除撤销；项目检查清单单独在左栏显示，已有清单不复制或丢失。文字块用浅面圆角容器、无框标题/原生textarea，正文自动高度、最小72，hover/focus可辨；编辑中不丢焦点或覆盖草稿，纯文本不自动推断交付。
- 只统计用户指定list；一个镜头一行，标签/日期/交完分别编辑，切标签不改日期。单元格失焦/选择后的保存刷新卡片、摘要和今天；异步回执只确认提交版本，不覆盖之后的手改。

### 项目清单（2026-10-03已确认）

- 项目级、允许多个分组，不强绑某张list，不自动同步今天或改变镜头交付状态。左栏浅底/圆角14，固定头部含清单图标、标题、真实待检查/完成数量和新增入口；中间分组区滚动，底部提示或删除撤销入口保持可见。
- 分组为同体系圆角10的小卡片，内距12；可直接编辑标题，右侧完成数如2/4及紧凑操作菜单，下方3高细进度条。全组完成用成功语义，空组不伪装成完成；菜单可上下移动/删除分组。
- 事项行包含20视觉复选框、可编辑事项和单项删除，文字13/22，长文自动增高至200后内部滚动；完成后变淡/删除线但不消失。新增/删除按钮用紧凑线性图标（新增组32、单项删除24、添加事项行≥36），hover/focus清楚，不能只出现无说明的空白框。
- 空栏/空组有说明和真实新增入口；新建定位标题或事项，删除后焦点转到邻项/添加入口。文字离开输入区按既有项目保存，结构变化按既有提交规则处理；删除事项/分组可单次撤销，等待与失败保留输入和操作保护。

### 办公式list与标签（2026-10-03，含最新反馈修订）

- 标题、工具栏、语义table、增删入口和底部说明属于同一圆角14的list容器，内距16/细轮廓；表头44、行≥44、单元格内距4，轻网格分隔行列。表头保留列名、拖动手柄和短菜单，不显示A/B/C/D字母列标；左侧保留行号操作区、当前格实体强调框与当前行/列浅选中提示。默认宽度权重：镜头176、阶段160、日期184（含日历入口）、交完112、文字176、行号64；用户列宽可在112～640内调整并随文档保存。
- 行号与列头含拖动手柄，拖行/列仅调整顺序不重建ID或转换字段；目标边有落点提示，鼠标和键盘菜单（上/下移、左/右移）均可用。100行分页内拖行，不声称跨分页拖动；跨页完整数据仍保持。列边提供可键盘调宽的分隔条，拖动预览不发每像素保存，松开一次提交；Escape取消预览。
- 行/列短菜单含相邻插入、移动、删除；列菜单还可改名，新增普通列不冒充语义列。删除单次撤销仍沿用原逻辑；无效/等待不误删。常驻整行“删除行”按钮撤掉，操作不再只有删除。
- Tab/Shift+Tab按控件移动，Enter/Shift+Enter上下格，方向键上下换行、左右在文本边界换格；F2把光标放到末尾编辑。IME确认不移动；文本方向键仍能正常编辑，阶段/日历浮层的按键由浮层负责。不追加多格填充、公式、合并或完整Excel。
- 常规增删列优先按list容器拟合显示宽度，不按每个新列的默认宽度不断延长整表；达到112的最小可读宽度仍放不下的极多列，才在具名、键盘可滚的表内区域横向查看。不得裁数据、藏滚动条冒充解决或擅加列分组切换。多行在表内纵滚，上限min(52vh,460)，表头固定；大list仍按100行分页、完整数据保存，跳原行到所在页，不让表格撑破主容器。
- 项目阶段组件不是原生select：按钮/单选listbox、按钮旁top-layer锚定浮层，不参与行高、不被局部容器裁切。选择区宽224，选项一项一行、最多四项高度（含未设阶段），更多只滚选项区；底部新增/管理按钮固定可见，不横向铺标签或每项占一大片空白。
- 单元格和下拉标签共用带底色的小圆角样式，不同标签用不同色相，未设阶段为中性；选中态有描边/勾号，勾号紧贴标签，不仅靠颜色。超长名可省略并提供完整名称，空间不足时浮层翻转/限高；方向键/Home/End移动并露出当前选项，Enter/Space选择，Escape返回触发按钮，外点不抢外部焦点，Tab可离开。
- 新增/管理/改名在同一浮层内切换（编辑/管理宽280），输入保存或取消不撑开文档；新标签保存并选用于当前行，其他行复用当前项目标签，改名保ID、被引用标签不能直接删除。亮暗用同一布局，标签多色不改变阶段/交期/已交完的独立语义。
- 保存中的结构操作仍受保护，连点不能重复提交；仅就地保存状态变化，无关标题/正文/按钮不因快速禁用/恢复整片褪色。正常保存不反复插入成功段落挤动正文；错误/未确认结果仍明确展示并保输入，不能为消闪取消数据保护。
- 删除行/列/块可撤销；移除语义列再启用汇总时补列，撤销有新值冲突须明示而非静默失效。非法日期/名称保输入，不污染正式记录；部分输入/保存错误与等待状态有就地反馈。

### 资料核对（S05状态需补齐）

正常页展示原件副本/出处、提取草案、目标旧值/新值、原始多日期、缺年份/冲突选择、应用结果。未核对不能应用；核对期间基线变更整批拒绝。取消保草案，失败可手填，不将固定演示冒充任意文件已解析。

视觉参考 `design/project-document.html` / `design/projects.css`；`design/s02-projects.html`补新行状态。当前生产页面按本节最新全容器/小卡片/清单/标签规则；旧HTML的居中窄栏、大卡片、正文下方清单与字母列标不再覆盖这些修订，也不覆盖单镜头行、独立日期和交完语义。

## 4. 资讯阅读与整期导出（2026-10-03修订）

- 资讯采用AIHOT式阅读结构，不整站照搬。上方阅读入口为“精选 / 全部动态 / 热点 / 日报”，默认精选；下方仅一套“全部 / 大模型前沿 / AI行业动态 / AI视频、图片 / CG应用”领域入口，“全部”不是第四领域；当前热点与新闻流共用筛选，不另加内容类型栏/领域下拉。
- 浅色阅读底 `#FAF9F6`、新闻面白色，暗色沿用工作台灰阶，强调色不变。精选/动态使用日期、左时间轨、右新闻面，一条一面，不变任务行/装饰卡墙；热点按事件聚合，同一事件显示代表报道和来源数，可展开关联进展。首页摘要最多3个，不限制整库条数。
- 来源在标题上，Feed标题17/26/650、摘要15/26、推荐理由13/22且标Agent判断。多源/后续进展页内渐进展开，标题进入文章页；回列表保留筛选/滚动，无结果有恢复入口。
- 文章：中央正文680～760宽，空间不足可至480；左侧来源/发布时间/目录，右侧推荐理由/标签/材料。≤1280右侧移文后，≤1100左侧移文前可折叠。目录滚正文，不造路由/弹窗。
- 详情先显示“AI导读”，再显示可用正文及中文/原文切换；旁栏推荐理由明确AI判断，含证据限制、主题标签和相关报道/进展。未取得正文/无全文许可明确说仅摘要/链接，不让AI补写冒充原文；无模型标待处理。事实/翻译/分析/未验证项分层，必要出处与失败不隐藏。
- 整刊页呈固定日期、版本、完整起止窗口、总览/看点、各领域和来源URL。屏幕/复制/A4 PDF用同一有序刊期内容，不受列表筛选影响；长刊分页不截断，不含应用壳/公司/会话/认证。桌面取消不报成功，复制受限保手选全文。
- 整理中、无热点、部分源失败、模型失败/重试有不同状态，旧刊可读；不自动补假正文或盲付费重试。新增来源/领域的合法性和下次生效提示在设置页，不增加发版门槛。
- 首个子交付先提供明确标为“采集资料 / 待AI处理”的真实原始资料入口，不冒充已精选动态；展示来源、原始标题、原发布时间/未提供、发现时间、摘要与原文链接。资讯页提供手动采集及“管理信源”入口，AI精选/热点/日报未接通前不放假按钮或示范新闻。
- 设置→资讯管理采用正常管理页：概览入口留在共用设置；信源列表与采集记录全宽，编辑/新增为二级正常页，返回不丢草稿。来源行显示名称/RSS或Atom/覆盖范围/身份/参与用途/启停、最近尝试/最近成功/结果；编辑页主表单包含名称、公开订阅地址、身份、覆盖领域、参与用途，高级区放频率。18个预置来源不自动覆写；新建来源默认暂停。预览显示前20条及取得总数，不保存或发布；保存成功明确配置版本和下次生效。
- 来源状态用文字区分未采集、正常有新增、正常无新增、抓取失败、解析失败、保存失败；待AI处理与采集成功分开。已有列表读取/采集中保持可见，错误就地展开，重试不丢输入；暂停说明保留历史。首期未接领域规则/模型步骤/自动运行时只说明后续接入，不展示可操作假设置。亮暗沿用tokens，通用控件≥40，长URL断行；≤1100来源元信息纵向排，不整页横滚。

## 5. 模型榜

- 沿用亮暗tokens：渐变头部、文本切榜、前三卡及完整长表，展示Agent Overall与文生图Overall各前50、保持官方原序；长名称可换行，表格使用具名可键盘横滚区域。
- 头部提供Arena原榜与刷新，仅显示采集时间；移除大段取数说明卡、成功提示条、字母占位头像、指标底色色块和标题/切榜图标。保留读取、采集/保存、取消、空态和失败反馈，不因简化隐藏失败。
- Agent只显示好评与投诉（含区间）、价格两组指标；价格为美元/百万token的输入/输出，缺价“—”。前三卡和表格不显示服务商名称，表头不写Models.dev；完整报价身份、厂商直供/第三方属性、模型ID和采集时间悬停可查，页脚保留Models.dev来源。净改善、确认成功、可引导性仍存快照，不在页面显示。

## 6. 通用Agent与模型设置

- 正常聊天页面：会话列208、消息流、底部composer；≤1100会话列改顶部可展开。通用输入，不做任务表单或弹窗，不把后台日志塞到空聊天里。
- 输入Enter发送、Shift+Enter换行，IME确认不发送；发送/steer/follow-up/停止有真实状态归属。消息/表单按会话保存草稿，切页/主题/会话不混写，失败保输入。
- 流式正文、思考/工具过程、输入/结果按类型展示；长输出可折叠，正常错误默认展开。accepted/handled、等待、完成、错误、中断区分，`agent_end`不能单独证明成功。
- 无模型或unknown提示“请先配置模型”，保草稿、禁发送，不假答。图片/工具能力不足先说明、保附件，不假调用成功。
- 模型设置字段写清地址/模型与原生配置状态；Key密码输入、只写不回显，留空保原Key，连接/保存失败保非密钥表单。实际可用清单来自Pi，不来自Arena；任意反代枚举未验证不许承诺。

- 页面恢复最近20条接受态只用于恢复显示/草稿，不执行、不自动重发。S04资源/TUI尚未接通前不展示假按钮；扩展请求与独占交接另补状态。

## 7. 灵感、任务、设置与系统状态

- 灵感响应式卡片网格；新增与各卡编辑草稿分别保存，切卡/切页/保存别卡不混写。内容必填、其余可选，搜索/标签/公司筛选、删除撤销、可选转待办防重，不强任务化。
- 任务页突出实际对象、状态、下一步和异常；父子/排队/工作/待确认/成功/中断/失败同源，过程按需展开。重试有副作用提示，重启不盲续写。
- 设置是正常配置页，不做仪表盘；数据根查看/打开，首次未设置/取消/无权限/占用/保存失败均保输入。完整迁移/备份/恢复未接时不得假成功。
- 资讯管理入口及其信源列表/编辑/预览状态按第4节；领域筛选、AI模型与采集运行配置随对应交付接入，执行日志链接到后台任务，不另部署网站后台或做统计仪表盘。动态资讯表单校验、下次生效/历史不变、草案未确认状态清晰。备份包清单/校验/恢复前副本/坏包拒绝在正常页，破坏性确认才用弹层。
- 桌宠五态+未知有文字/形状，点击定位任务，隐藏/托盘/设置可找回，不抢焦点；真实系统浮窗/DPI另验，不拿网页代替。

- 每阶段补主流程起点/中间/结果以及空、加载、失败、保存/取消、破坏性确认；二级入口有返回。错误、来源与必要风险不为“干净”隐藏，长帮助按需展开。
