# AZCine 产品需求

> 更新：2026-10-08。只保留当前有效范围、用户决定、需求状态与验收；旧稿不再是执行依据。

## 1. 产品目标与范围

给用户本人使用的 **Windows 影视 CG + AI coding 个人工作台**：公司项目文档与交付、待办、通用 Agent、热点资讯、Arena 模型榜、灵感、自用记账和本机后台工作都保留。采用 Tauri 2 / React / TypeScript / Rust 单写入者 SQLite / 独立 Node-Pi 官方 RPC，不用 Electron。

主流程：今天接续工作 → 公司项目卡片 → 自由文档/list → 当前交期与阶段汇总；主动资料 → AI草案 → 本人核对 → 正式更新。通用Agent不收窄为固定按钮；资讯是面向三个关注领域的私人资讯台，包含精选、全部动态、事件热点、详情阅读与固定日报，不是原始新闻堆砌，也不限于当前项目。

共用界面：顶部、左侧导航和模块标题保持在窗口内，模块内容在右侧固定容器内部滚动，不带动整个软件外壳。此规则适用于所有现有及后续模块，不代表其他模块的业务功能已实现或获开发授权。

### 公司记录

- 一个镜头在list中只有一行，行ID稳定；项目独立、自定义、单选的当前阶段标签，改名保留稳定标签ID。ACOPY/FINAL切换不新建行。
- 日期规则A：标签与当前交期各改各的，切标签不改/清空日期，改日期不切标签；不建立自动阶段日期映射。独立“已交完”可恢复，FINAL不自动完成。
- 用户指定哪些list参与汇总，普通笔记/参考表不自动推断。汇总使用当前行日期、镜头与标签，能回原行；不猜编号关系、缺年份、完成状态或项目总截止日。
- 可增改文字、表格list、项目级检查清单与自定义列，排序、删除/撤销。项目页使用整个主容器排版，入口保持小卡片；详情左侧是项目共用的多个清单分组，右侧是交付摘要、list与文字，两侧独立滚动。已有清单保留内容与ID，不在正文底部重复显示；清单事项支持编辑、勾选、单项删除/撤销，不自动进入今天或改变镜头交付状态。标签是阶段，不是制作部门；无团队/客户审批。
- 文档、Excel、截图和粘贴由用户主动提供；副本/出处/原始多日期保留，本人选当前交期。草案带目标基线，核对期间手改后整批拒绝旧草案，不部分覆盖。个人coding项目内部仍待定，仅保留入口。

### 资讯、模型榜与后台

- 初始三个领域：“大模型前沿”“AI行业动态”“AI视频、图片 / CG应用”（最后一项为一个领域）。仅一套领域筛选；AI coding、Agent、视频生成、三维等作主题标签，发布/评测/研究/教程等作内容类型标记，不另加一套类型筛选栏。
- 首批只用AIHOT开源仓库公开的18个RSS/Atom示范信源，不代表其线上完整名单。来源定义固定于提交 `cc66cceb1dc7a0bc147e942e49ff94c9cee418c6` 的 `industry/sources.json`；名单已获用户确认，但逐源实际可用性尚未验证。后续新增/付费来源由用户提出，不自行扩源或开通收费服务；影像/CG覆盖不足不凑内容。
- 采集/补齐/初步去重→AI预筛、事实与领域提取、评分→事件归组→中文导读/推荐理由/允许的正文翻译→阅读与成刊。正常先评分一次，临界入选、证据冲突或归组不明确再复判；评分只表示推荐价值，不表示事实正确率。热点按独立来源与时间计算，不称全网热度；日报按已整理内容的规则成刊，不让模型另编新闻。
- 当前统一阅读默认全部报道，只保留一排主题分类与搜索；处理结果保留入选信息，热点仍按事件合并，详情展示AI导读、原文/中文阅读、推荐理由、证据限制、相关报道与进展、出处及发布时间。事实/翻译/AI判断分开；这18个来源默认不启用站内全文，允许后才能显示正文，否则明确仅链接/摘要。无模型保留采集材料并标待处理，不出假导读。
- 默认北京时间09:00整理过去24小时，可手动；当天错过补一次，不连补多天。总览最多3、每领域最多5且可配置，只约束日报/首页摘要，不限制资讯库收录数量；无热点不凑数。刊期不可变，区分事实、分析和未验证项。
- 整期复制/A4文本PDF包含固定版本、窗口、各领域和出处URL，由用户自行转发，不夹业务或认证。设置→资讯管理包含信源、领域与筛选、AI处理、采集与运行；不另部署网站后台或增加账号。来源可编辑/启停/预览，最近成功时间、无新增/抓取失败/解析失败/AI失败分别可查，失败只重试对应环节。支持类型的来源、领域与规则可在设置或确认Agent草案后改变，不必每次发版；不承诺任意链接、登录或新协议可抓。配置下次任务生效，运行中固定配置，暂停不删历史，旧刊不重写。
- Arena采用 Agent Overall 与 Text-to-Image Overall 各前50名，保留官方原序和完整原始字段；Agent显示好评与投诉、输入/输出价，文生图显示分数/票数。价格接入Models.dev，单位美元/百万token，缺价“—”；不作为Pi可用模型清单。头部只显示采集时间，来源日期和完整报价详情仍存入快照。
- **来源边界**：实现从Arena发布的Hugging Face数据集自动取数，不抓取Arena网页或隐藏接口，不要求用户准备导入文件；公开数据与原站可能不同步。每日首次进入尝试一次、支持手动刷新与取消、失败保旧；来源不可用不伪造更新。本轮仅核对合并源码和交接记录，未重新联网复核来源条款或可用性。
- 后台最多2个执行单元，子任务也占槽、父任务等待时释放槽；自由任务、父子关系与日志可追溯。应用在Pi进程外编排，不暗装委派扩展，不保证原版模型自主调用OpenPI式spawn。
- 主窗关闭收托盘、明确退出中断确认、登录自启默认关为后续功能；睡眠/关机不执行。桌宠五态（空闲/工作/等确认/暂停/错误）加断连未知，拖动/隐藏/重开/定位任务，不养成或音效。

### 自用记账

- 以记开销、算人民币总数和走报销为主；日期/用途/金额/备注、月份/状态/搜索筛选及勾选统计。不扩展成复杂财务、多人报销或自动对外提交系统；样式沿用本项目UI库。
- 外币按开销日期取得报价，入账保原币、人民币折算、实际报价日期和来源；该日无新报价时使用之前最近公布值，不冒充当日实时汇率。报价失败或币种/日期不匹配保输入，不自动采用旧结果。
- 当前已实现票据副本、系统打开与CSV导出、软删除/最近一次撤销、报销状态与本人确认；这些实现尚未验证，不替代完整数据备份或用户验收。

### Pi、数据与费用边界

- Pi为纯上游原版，runtime与全部状态相对外部Pi/LYWork/OpenPI/宿主独立；同仓库正常开发Worktree共用main自有配置/认证/会话/Skills/扩展/模板/主题，测试与正式版使用自身根；保留上游内置能力、自定义资源原则上由用户按原生机制添加；本次用户明确授权的自动标题扩展和应用azcine MCP条目为例外。不改核心/默认系统提示，不共享或更新其他Pi/LYWork/OpenPI，不全局安装、不运行PATH中的其他Pi。
- 原生RPC与TUI共用本应用runtime/配置和会话，一次一个写入者。资源来源、外部cwd迁移/发现、受控进程树清理须实测；独立目录不等于OS沙箱。无扩展下做不到的原生行为明示缺口。
- 工作台内配置地址/Key/模型，不搬宿主认证，不保证任意反代自动枚举。用户发送或启用的任务可消耗已配置API配额；不另开收费服务、不盲重试、不读取凭据环境。无模型正常入口提示配置并保留输入，不能假回复。
- 默认系统文档目录 `AZCineData`，可改的单一本机根包含业务/附件/快照/Pi会话及应用资源配置；程序和可重建缓存另计，本机定位配置只指向根。
- 导入副本不改原件/不静默覆盖。迁移暂停写入/Pi/调度，复制校验后切根，保留旧根、不自动合并不同库；失败保输入和原记录，不默默建空库。
- 业务有变化每日最多一次自动完整一致备份，最近7份，只轮换应用自动旧包；手动包/原件保留。包含库/附件/快照/原生会话/非凭据资源配置与清单，不递归backups，排除认证、Key、认证引用和 `pi/private-config-transactions/`。
- 恢复先核包/版本/哈希、保当前副本、暂停写入、本人确认；坏包或失败不覆盖当前数据，认证需重配应提示。OneDrive用户自管，不做应用云同步、多机编辑/合并，不承诺活跃SQLite外部同步一致性。

## 4. 首版验收基线

原有15条首版已确认需求保留集中确认后的验收原文；交互补充R-005-E/R-004-D及最新R-005-F已确认，修订带日期另列；实现、技术检查和用户验收仍分开，不冒称整条已验证。2026-10-03用户通过范围是今天/待办＋公司项目当前已实现的本地页面，不包括未接入的导入与依赖信息；最新改动未运行技术验证或独立复核。模块内部只选相关子项，不另造不同标准。

### R-001 领域资讯阅读与热点摘要（2026-10-03修订；后台定时接入）
- **流程与输入输出**：18个已确认的公开RSS/Atom源→采集材料去重、本地保存→AI预筛/事实分类/评分/归组/中文整理→统一报道列表、入选标记、事件与文章详情。手动或09:00从已整理内容生成过去24小时不可变刊期。原始资料与结果关联，来源默认仅链接/摘要；合法正文另按许可保存/展示。
- **边界/异常**：三个初始领域不变，内容类型只作标记。观测来源覆盖/关注线索和影视CG、AI coding价值，不称全网热度；总览最多3/每领域最多5仅约束日报和首页，空不凑。一次基础评分，临界/冲突/归组不明再复判，具体阈值需日后校准而非照搬AIHOT。无模型保留材料待处理；额外付费源/服务不自动开通，新增来源等用户指令。
- **R-001-A**：Given两源同事件及一条后续进展，When手动整理，Then合并一个事件入口、保留各出处和变化、不把旧稿当新热点；生成时间/起止窗口/配置版本/刊期版本可追溯，再整理产生新版本不覆盖旧刊。
- **R-001-B**：Given无热点、部分源失败或模型失败，When结束整理，Then分别为空刊/明示不完整/失败，旧刊仍可读、缺口可查，不编造正文或自动付费重试。
- **R-001-C**：Given同一新闻的多篇报道及无新增事实的转载，When浏览统一报道与事件详情，Then同事件集中展示出处与新进展，不重复占热点；范围内未入选内容仍可在统一报道列表查阅，评分不称可信概率。
- **R-001-D**：Given仅订阅摘要、未获全文许可或无模型，When打开材料/详情，Then明确摘要/原文入口及待处理状态，不生成假正文/导读/翻译；AI分析、来源事实和未验证项分层。

### R-002 事件分析（资讯）

### R-017 总根、保存/备份/迁移（共用设置/数据）
- **R-017-A**：Given默认或自选根目录，When保存并退出重开，Then业务/附件/快照/Pi会话/应用资源配置在该根可回查；主动导入副本不改原件、同名不静默覆盖，当前根可查看/打开。
- **R-017-B**：Given根目录无权限、空间不足或附件缺失，When保存/迁移不能完成，Then明确错误、保留输入/旧目录/原记录，不假成功、不默默建空库；When迁移成功，Then校验后切换并重开使用新根，旧根保留，已有不同库不得静默合并。
- **R-017-C**：Given当天业务有变化，When触发自动备份，Then每天最多一次且轮换最近7份，仅清理应用自动旧份；手动包/原件不删。包为库/附件/快照/Pi会话/非凭据配置一致快照并有完整清单，不递归包含backups，不含认证/Key；活动会话备份需协调暂停/稳定写入。
- **R-017-D**：Given手动导出包，When校验/本人确认恢复，Then先保当前副本、暂停写入、恢复后业务与附件会话对应；损坏/不兼容/失败不覆盖当前记录，认证未恢复要明确提示。OneDrive自管，不宣称活跃库多机一致性通过。

### R-018 自用记账

- **触发/输入/输出/优先级**：本人日常记开销及报销→日期、用途、金额、币种、备注和可选票据→持久开销、人民币合计、筛选/勾选统计与报销状态。以简化自用为主，不代替复杂财务或多人报销。
- **R-018-A**：Given合法或无效开销草稿，When创建/编辑/保存并继续或失败，Then合法记录按请求只保存一次，无效字段就地提示；失败/未知回执/关闭保输入，重开记录可查，修订冲突不覆盖后改。
- **R-018-B**：Given金额如70美元及开销日期，When取得报价并保存，Then按匹配币种/日期折合人民币，保原币、来源及实际报价日期；当日无新报价可用此前最近公布值但明确日期，失败或失配不入账且保输入。
- **R-018-C**：Given多笔人民币/外币开销，When月份/状态/搜索筛选、勾选、修改报销状态及删除撤销，Then人民币合计与所选范围一致，状态本人确认，撤销不覆盖后续修订；票据复制不改原件，打开/CSV导出取消不报成功。

### R-019 共用表单与反馈

- Given项目/待办/灵感/信源创建或开销创建编辑，When打开、关闭、保存、切主题或异步回执到达，Then背景保所属页面、草稿不丢、失败保输入；表单收起不先闪空内容，旧请求不能关闭后来弹窗。同一字段错误只归属当前表单，不重复到背景。
- Given一次操作回执，When完成或重复操作，Then顶部唯一通知显示最新结果并重新计时，普通4秒/撤销6秒、悬停聚焦暂停、可手动关闭；长期进度/失败/待核对仍有所属入口，取消不报成功。

### 项目删除与处理历史补充

- **R-005-G**：Given项目文档和关联草稿，When确认删除或从已删除列表恢复/撤销，Then删除退出交付汇总而保文档/关联/草稿，恢复对应记录，旧修订回执不覆盖后续变更。
- **R-015-E**：Given已结束及运行中资讯任务，When移除单条或清空已结束历史，Then确认范围绑定实际记录，运行中拒绝；只隐藏历史，保结果/快照/处理标记，已隐藏任务不能重试，清理对应已查看详情但保资料选择与范围草稿。

### R-020 仓库任务面板（任务面板；与应用聊天/后台任务分开）

- **输入输出/边界**：选择总仓库、任务目标/范围/验收、来源与本人决定 → 仓库内 `.azcine/task-panel/state.sqlite3` 权威任务记录和 `.azcine/task-panel/tasks/<id>/runs/` 上下文/交接/回执，执行位置可为所属Worktree。应用只记仓库入口，总仓库架构/记忆共用；不创建独立分支项目或任务库。不混用业务库application_id/版本，不把SQLite事件表冒充已实现events.jsonl重放。
- **R-020-A**：Given同仓库及其任务分支，When新建执行/选择分支/查看整体任务，Then仍为同一仓库身份/项目/看板，快照和Git状态来自实际执行目录；旧分支任务归并先备份保原件与ID，编号冲突有归并事件。
- **R-020-B**：Given确认的任务、Codex/OpenPI和窗格名，When自动建立Herdr执行窗格/分支并派发，ThenPowerShell按选择启动codex/opi，精确绑定实际身份；blocked/working/idle和失联分别记录，停止/恢复/重试只操作绑定执行，未核实的停止不当完成。
- **R-020-C**：Given任务交付、检查或Agent建图候选，When回填/导入/核对，Then实现、技术检查与本人验收分开；图谱执行层/代码层和来源可追溯，静态调用只作候选，源码不同不覆盖共享架构；重要目标/授权/决定/记忆应用仍本人确认。
- **R-020-D**：Given长详情、失败任务、待回答窗格和未确认记忆，When切视图/筛选分支/滚动/取消或返回原窗格，Then输入与来源不丢，正文换行/内部纵向滚动，可查真实失败/停止待核对及恢复入口，不因终端idle或模型口头完成自动验收。

### R-021 服务器和凭证

- **流程与范围**：工作台入口维护服务器资料、购买/到期日、续费金额/币种/周期、登录信息及关联凭证；凭证支持账号密码或SSH公私钥文件/口令/分类。正式入口从当前业务库加载，虚构数据只用于显式UI总览。限资料与应用内提醒，不增加解锁/远程终端/自动支付/对外通知/云同步。
- **R-021-A**：Given当前数据根，When新增、编辑或重开服务器/凭证，Then保存到本地库并显示实际结果；失败保输入，修订冲突或回执待核对阻止继续覆盖；切页/主题/关闭弹窗保本窗口草稿，切根排除旧根迟到回执。
- **R-021-B**：Given未来30天或已过期服务器，When查看提醒、清除红点或登记续费，Then提醒列表/计数和到期状态保留，已读按服务器ID与到期日记录，新到期日可再次未读；续费保留历史，无效日期不显示正常。
- **R-021-C**：Given用户选择的密钥文件，When导入或打开位置，Then复制到应用数据根、保留原件，打开经过路径/大小/哈希核对的副本目录；删除关联不自动删除文件。
- **R-021-D**：Given服务器或凭证及其关联，When确认删除，Then删服务器保留独立凭证和带名称的续费历史；删凭证解除已保存记录及当前草稿关联，保留服务器直接登录密码和文件；失败不冒充成功。
- **R-021-E**：Given较多记录或长文本，When搜索、筛选、分页或删掉末页记录，Then四类列表各自支持20/50/100条分页、有效页归位及内部滚动，表头固定；亮暗和键盘/焦点体验仍待授权验证。
