<p>Capabilities can affect multiple windows and webviews and these can be
referenced in multiple capabilities.</p>

<p>Capability files are either defined as a JSON or a TOML file
inside the <code dir="auto">src-tauri/capabilities</code> directory.</p>
<p>It is good practice to use individual files and only reference
them by identifier in the <code dir="auto">tauri.conf.json</code> but it is also possible
to define them directly in the <code dir="auto">capabilities</code> field.</p>
<p>All capabilities inside the <code dir="auto">capabilities</code> directory are automatically enabled
by default.
Once capabilities are explicitly enabled in the <code dir="auto">tauri.conf.json</code>,
only these are used in the application build.</p>
<p>For a full reference of the configuration scheme please see the
<a href="/reference/config/">references</a> section.</p>

<p>Capabilities can be platform-specific by defining the <code dir="auto">platforms</code> array.

<div class="sl-heading-wrapper level-h2"><h2 id="security-boundaries">Security Boundaries</h2><a class="sl-anchor-link" href="#security-boundaries"><span aria-hidden="true" class="sl-anchor-icon"><svg width="16" height="16" viewBox="0 0 24 24" fill="currentColor"><path d="m12.11 15.39-3.88 3.88a2.52 2.52 0 0 1-3.5 0 2.47 2.47 0 0 1 0-3.5l3.88-3.88a1 1 0 1 0-1.42-1.42l-3.88 3.89a4.48 4.48 0 0 0 6.33 6.33l3.89-3.88a1 1 0 0 0-1.42-1.42m8.58-12.08a4.49 4.49 0 0 0-6.33 0l-3.89 3.88a1 1 0 1 0 1.42 1.42l3.88-3.88a2.52 2.52 0 0 1 3.5 0 2.47 2.47 0 0 1 0 3.5l-3.88 3.88a1 1 0 0 0 0 1.42 1 1 0 0 0 1.42 0l3.88-3.89a4.49 4.49 0 0 0 0-6.33M8.83 15.17a1 1 0 0 0 .71.29 1 1 0 0 0 .71-.29l4.92-4.92a1 1 0 1 0-1.42-1.42l-4.92 4.92a1 1 0 0 0 0 1.42"></path></svg></span><span class="sr-only" data-pagefind-ignore>Section titled “Security Boundaries”</span></a></div>
<p><em>What does it protect against?</em></p>
<p>Depending on the permissions and capabilities it is able to:</p>
<ul>
<li>Minimize impact of frontend compromise</li>
<li>Prevent or reduce (accidental) exposure of local system interfaces and data</li>
<li>Prevent or reduce possible privilege escalation from frontend to backend/system</li>
</ul>
<p><em>What does it <strong>not</strong> protect against?</em></p>
<ul>
<li>Malicious or insecure Rust code</li>
<li>Too lax scopes and configuration</li>
<li>Incorrect scope checks in the command implementation</li>
<li>Intentional bypasses from Rust code</li>
<li>Basically anything which was written in the rust core of an application</li>
<li>0-days or unpatched 1-days in the system WebView</li>
<li>Supply chain attacks or otherwise compromised developer systems</li>
</ul>

<p>Tauri generates JSON schemas with all the permissions available to
your application through <code dir="auto">tauri-build</code>, allowing autocompletion in your IDE.
To use a schema, set the <code dir="auto">$schema</code> property in your configuration file
(either .json or .toml) to one of the platform-specific schemas
located in the <code dir="auto">gen/schemas</code> directory. Usually
you will set it to <code dir="auto">../gen/schemas/desktop-schema.json</code> or
<code dir="auto">../gen/schemas/mobile-schema.json</code> though you can also define a capability
for a specific target platform.</p>
